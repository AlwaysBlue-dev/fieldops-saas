# FieldKeel — Web

Next.js App Router client for **FieldKeel** (field service and operations management).

Set `NEXT_PUBLIC_APP_NAME=FieldKeel` and `NEXT_PUBLIC_API_URL` (see `.env.example`). Production/staging URLs come from environment configuration — do not hardcode `fieldkeel.com` for redirects.

```bash
fnm use 24.14.1
npm install
npm run dev
```
